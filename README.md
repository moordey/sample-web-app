# Notes API

Простой веб-API сервер на Python для управления заметками с аутентификацией. Разработан для тестирования и демонстрации e2e-сценариев.

## Особенности

- **Аутентификация**: Регистрация и вход пользователей с токенами
- **CRUD операции**: Полный набор операций для управления заметками
- **Безопасность**: Защита всех эндпоинтов через Bearer токены
- **База данных**: SQLite с автоматическим созданием таблиц
- **Контейнеризация**: Docker и docker-compose для простого развертывания
- **Документация**: Автоматическая генерация документации на `/docs`
- **Логирование**: Полноценная система логирования для отладки и мониторинга
- **Валидация**: Строгая валидация входных данных через Pydantic

## Технологии

- **FastAPI** - Асинхронный веб-фреймворк
- **SQLAlchemy** - ORM для работы с базой данных
- **SQLite** - Легковесная база данных
- **Pydantic** - Валидация данных и сериализация
- **Passlib** - Хеширование паролей
- **Python-JOSE** - Работа с JWT токенами
- **Docker** - Контейнеризация
- **Uvicorn** - ASGI сервер

## Быстрый старт

### Запуск с Docker (рекомендуется)

1. Склонируйте репозиторий
2. Запустите:

```bash
docker-compose up -d
```

Сервер будет доступен на `http://localhost:8000`

### Запуск локально

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Запустите сервер:

```bash
uvicorn src.main:app --host 0.0.0.0 --port 8000 --reload
```

## API Эндпоинты

### Без аутентификации

- `GET /health` - Проверка работоспособности сервера
- `POST /auth/register` - Регистрация пользователя
- `POST /auth/login` - Вход пользователя (получение токена)

### С аутентификацией (требуется Bearer токен)

- `POST /auth/logout` - Выход (инвалидация токена)
- `GET /auth/me` - Информация о текущем пользователе
- `GET /notes` - Список заметок пользователя
- `POST /notes` - Создание новой заметки
- `GET /notes/{id}` - Получение заметки по ID
- `PUT /notes/{id}` - Обновление заметки
- `DELETE /notes/{id}` - Удаление заметки

## Примеры использования

### Регистрация пользователя

```bash
curl -X POST "http://localhost:8000/auth/register" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "testuser",
    "email": "test@example.com",
    "password": "password123"
  }'
```

### Вход и получение токена

```bash
curl -X POST "http://localhost:8000/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "testuser",
    "password": "password123"
  }'
```

### Создание заметки

```bash
curl -X POST "http://localhost:8000/notes" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Моя первая заметка",
    "content": "Это содержимое моей первой заметки"
  }'
```

### Получение списка заметок

```bash
curl -X GET "http://localhost:8000/notes" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Переменные окружения

- `DATABASE_URL` - URL базы данных (по умолчанию: `sqlite+aiosqlite:///./data/app.db`)
- `SECRET_KEY` - Секретный ключ для подписи токенов (обязательно изменить в продакшене!)
- `TOKEN_EXPIRE_HOURS` - Срок жизни токена в часах (по умолчанию: 24)
- `DEBUG` - Режим отладки (по умолчанию: false)

## E2E-сценарий для тестирования

1. Регистрация пользователя
2. Вход (получение токена)
3. Создание заметки
4. Получение списка заметок
5. Обновление заметки
6. Получение информации о пользователе
7. Выход (инвалидация токена)
8. Попытка доступа с инвалидным токеном (должна быть 401)

- `http://localhost:8000/docs` - Интерактивная документация (Swagger UI)
- `http://localhost:8000/redoc` - Альтернативная документация (ReDoc)

## Docker-оптимизации

- Ограничение памяти контейнера (512МБ максимум)
- Ротация логов (максимум 3 файла по 10МБ)
- Запрет отладочного режима в контейнере
- Безопасный пользователь nobody для запуска приложения

## Логирование

Приложение использует полноценную систему логирования:
- Информационные сообщения о регистрации, входе, операциях с заметками
- Предупреждения о неудачных попытках входа и доступе без токена
- Ошибки с деталями для отладки
- Логи сохраняются в директорию `logs/` (в контейнере)

## Безопасность

- Пароли хешируются с помощью bcrypt
- Токены имеют ограниченный срок действия
- Все эндпоинты защищены аутентификацией
- CORS настроен для безопасности
- Приложение запускается от имени непривилегированного пользователя
